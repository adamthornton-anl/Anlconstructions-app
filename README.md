# AnlConstructions Time Tracker

A simple time tracking app for construction workers.

## Features

- ✅ Worker login with PIN
- ✅ Check-in / Check-out tracking
- ✅ Lunch break deduction
- ✅ Weekly hours summary
- ✅ Pay calculation
- ✅ Job location & materials notes
