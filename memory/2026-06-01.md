   - Simple, fast interface for on-site use

2. **Lunch Breaks**

   - Notes → materials list compiled
   - Materials list sent/visible to Adam

4. **Dashboard for Adam**
   - Daily hours per worker (minus lunch)
   - Location data from check-outs
   - Materials list aggregated
   - Real-time updates
