## Technical Details

### Frontend (`public/index.html`)
- Single-page app (SPA)
- Two main sections: login & tracker
- Uses `App` object with methods:
  - `init()` — Initialize app
  - `selectWorker(name)` — Select worker
  - `login()` — Validate PIN & authenticate
  - `checkIn()` — POST start_time to API
  - `checkOut()` — POST end_time to API
  - `save()` — POST full entry (lunch, job, materials)
  - `loadEntries()` — GET entries from API
  - `renderWeek()` — Display hours chart
  - `logout()` — Clear session & reset form

### Backend (`api.js`)
- Express.js server
- Routes:
  - `POST /api/login` — Verify worker + PIN
  - `POST /api/entry` — Create/update time entry
  - `GET /api/entries/:user_id` — Retrieve entries
  - `GET /api/workers` — List all workers
  - `GET /api/health` — Health check
  - `GET *` — Serve HTML (SPA)

### Database (Supabase)
- `users` table (4 workers with PINs & rates)
- `time_entries` table (stores all logs)
- All endpoints tested and working
